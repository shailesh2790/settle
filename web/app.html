How it thinks

An LLM reasons by writing one token after another. Settle reasons by updating a hidden state across the whole grid at once. Every step it looks at its current state and at the maze again, then refines the state. The same four small 3×3 convolutions run at every step, so harder mazes need more steps, not more parameters.

# encode the problem once
h0      = relu(conv(x))
# recall: the maze is re-injected every step
a_t     = relu(conv([h_t, x]))
# bounded update, same weights every step
h_t+1   = tanh(h_t + conv(a_t))
# every cell answers in parallel
answer  = conv(h_T)

It halts when the thresholded answer has not changed for four consecutive steps. Switch the view to Hidden state to see the activity spread outward from the start and goal.

Knowing when there is no path

The original model never admits a maze is unsolvable: on 80 test mazes with the route cut, it drew a path through every one. The retrained model says “no path” on all 80, even at 31×31. That honesty is what lets a search trust it. In the Arena tests, search guided by the retrained model solved 58% of 41×41 mazes (the original alone: 25%) and its confidence separated right from wrong answers perfectly.
