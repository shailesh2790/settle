Sudoku Lab

A small network that learned Sudoku from solved examples. It was never told the rules. It thinks by updating every cell together until the grid checks out. When it gets stuck, verified search guesses the cell it is least sure of and lets each guess settle. Everything runs on your device.

How it thinks

Each cell keeps a hidden state. Every step, each row, column and box pools what its cells currently believe, and each cell hears back what the rest of its group believes. The same small update then runs on every cell. The model knows which cells share a group, but not that a group must hold 1 to 9 once each. It learned that from solved examples.

# per step, same weights every step
rest   = sum(group) - me          # the rest of my row / column / box
msg    = relu(R·rest + S·me + type)
h      = norm(h + MLP([h, puzzle, msg]))
answer = argmax(out(h))           # all 81 cells at once

It stops as soon as the grid passes the checker. It never returns an answer that breaks a rule. At worst it says it could not solve the puzzle.

How good is it

The current model trained for 3 hours on a laptop GPU. It still has only 233k parameters, but it now handles many puzzles that need guessing on its own, and search covers most of the rest. Results on 200 random held-out puzzles, with the 10-minute model for comparison:
