Settle Maze Sudoku Code

Reasoning that runs on your own laptop

Settle models don't write an answer one token at a time. They hold the whole problem in a hidden state and refine it in place, applying the same small update over and over until the answer stops changing or passes a checker. They have thousands of parameters, not billions, and run in this page with no server and no GPU cluster.

Maze

Finds the shortest path through a maze by spreading belief across the grid. Trained on small mazes, it keeps working on larger ones by thinking longer.

Compute follows difficulty

Easy problems settle in a few steps and hard ones take more. The model stays the same size and just thinks longer.

Answers you can check

When a problem has rules, the model stops only when its answer passes them. It says "not solved" rather than guess wrong.

Small enough to own

Every model here trains on one laptop and runs on any device. The code and weights are plain files you can retrain.

Experimental research code. Each model's results are measured on held-out puzzles and listed on its page.
